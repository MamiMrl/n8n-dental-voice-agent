# ADR 0005: Repo named `n8n-dental-voice-agent`, MIT licensed

Date: 2026-07-06
Status: Accepted

## Context

The repo name is the first thing seen in the GitHub profile grid and in search.
A branded name (e.g. "emma-voice-agent") is memorable but opaque; a descriptive
name is discoverable by people searching for exactly this kind of build.

## Decision

Name: `n8n-dental-voice-agent` — keyword-rich (n8n, dental, voice agent),
matches the workflow name. License: MIT — showcase value is authorship, not
secrecy, and MIT is a precondition for the later reusable-template pivot
(ADR 0001).

## Consequences

- Discoverable via GitHub/Google search for "n8n voice agent".
- Anyone may reuse the workflow/prompt; attribution not enforced.
